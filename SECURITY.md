# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in SPINFORGE, please report it responsibly by contacting the maintainer via GitHub Security Advisories or by emailing `mrinalprakash9123@gmail.com`.

Please include:
- A description of the vulnerability.
- Steps to reproduce or proof-of-concept.
- Potential impact.

We will review reports within 48 hours and provide patches as quickly as possible.
